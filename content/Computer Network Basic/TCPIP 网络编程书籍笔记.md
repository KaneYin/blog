# 理解网络编程和套接字（Socket）

- 网络编程：简单来说，就是编写程序使两台连网的计算机相互交换数据。
- 套接字（Socket）：操作系统提供的一种用于网络传输的软件设备。 

## 什么是套接字（Socket）
我们把插头插到插座上，就能从电网获得电力供给，同样为了与远程计算机进行数据传输，需要连接到 因特网，而编程中 **“套接字“** 就是用来连接该网络的工具，它本身就有“连接“的含义，**还可以表示两台计算机之间的网络连接**


## 构建Socket的过程

套接字大致分为两种，其中，首先要讨论的就是 TCP 套接字，也可以比喻为电话机。电话机就是通过固定电话网完成语音数据交换的，所以，我们熟悉的固定电话语套接字实际上并没有很大的区别。下面利用电话机这个比喻理解套接字的创建以及使用方法。

电话可以用来拨打和接听，但是对于 Socket 而言，拨打和接听是有区别的，首先讨论==用于接听的 Socket 创建过程==。

	- 调用 Socket 函数的过程就相当于安装电话机。

### 服务端套接字的创建过程
网络编程中接受连接请求的**套接字创建过程**可以整理如下：
1. 调用 socket 函数创建套接字。
2. 调用 bind 函数分配 IP 地址和端口号。
3. 调用 listen 函数转化为可以接收请求的状态。
4. 调用 accept 函数受理连接请求。

记住这些步骤相当于为 Socket 编程勾勒出了轮廓，后续部分会为这些内容上色。
