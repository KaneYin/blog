首先我们可以先以一个经典面试题为例，讲解字符串常量池。
**new String("AB") 创建了几个对象？**
```java
String s = new String("AB")
```
在理解字符串常量池的内容之前，可能无法理解这个问题考察的内容，其实这个语句创建了两个对象。
使用 new 关键字创建一个字符串对象的时候，Java 虚拟机会先在字符串常量池中查找有没有 “AB” 这个字符串对象，如果有，就不会在字符串常量池中创建 “AB” 这个对象了，直接在堆中创造一个 “AB” 的字符串对象，然后将堆中这个 “AB” 的对象地址返回赋值给变量 s。
如果没有，先在字符串常量池中创建一个 “AB” 的字符串对象，然后在堆中创建一个 “AB” 的字符串对象，然后将堆中字符串对象地址返回给变量 s。
# 什么是字符串常量池
Java 中的字符串常量值是堆中的一块存储区域，里面存储了程序中定义的所有字符串。JVM 虚拟机查看 String pool 中是否存在某一个字符串对象，如果存在，同一个对象的引用就会共享给变量；如果不存在，才会在 JVM 中创建一个新的字符串对象。
## 🌰例子
下面是两个 Java 程序的例子，第一个程序的输出是 “Yes”，但是第二个程序的输出是 “No”，原因是什么呢？
```java
// Program 1: Comparing two references to objects
// created using literals.
import java.util.*;

// Driver Class
class GFG {
    // main function
    public static void main(String[] args)
    {
        String s1 = "abc";
        String s2 = "abc";

        // Note that this == compares whether
        // s1 and s2 refer to same object or not
        if (s1 == s2)
            System.out.println("Yes");
        else
            System.out.println("No");
    }
}
```
Output:
```
yes
```

```java
// Program 2: Comparing two references to objects
// created using new operator.
import java.util.*;

// Driver Class
class GFG {
    // main function
    public static void main(String[] args)
    {
        String s1 = new String("abc");
        String s2 = new String("abc");

        // Note that this == compares whether
        // s1 and s2 refer to same object or not
        if (s1 == s2)
            System.out.println("Yes");
        else
            System.out.println("No");
    }
}
```

Output:
```
No
```

> 原因解释：
> Java 中字符串最重要的性质就是不可变。也就是说，一旦创建，字符串的内部状态在程序运行过程中始终保持不变。这种不可变性是通过堆中特殊的字符串常量池来实现的。

## How String Pool Works
在 Java 语言中，字符串是这样定义赋值的：
```java
String str1 = "Hello";
```
我们用一个图表解释底层发生了什么事情：
![[图解字符串常量池]]
字符串对象创建在栈中，但是字符串值 “Hello” 是创建并存储在堆中的。因为我们个这个值附了一个变量，所以 Str1 指针就指向堆中存储的 “Hello” 字符串。现在，我们举一个同样的例子，也就是多个变量赋值给同一个字符串常量：
```java
String str1 = "Hello";
String str2 = "Hello";
```
![[图解字符串常量值 2]]
这种情况下，字符串变量都创建在栈中，但是另一个 “Hello” 字符串的值并没有在堆中创建，相反，以前创建的 “Hello” 字符串被重新使用了。字符串常量值是一个在堆里面的一个小缓存区。Java 将所有直接赋值的字符串存储在字符串常量池中。也就是说，字符串常量池主要是用于减少内存的使用并未提高内容中已经存在常量的使用。
In Java, using `new String("Hello")` always creates a **new object in the heap**, even if `"Hello"` already exists in the string constant pool. This is because the `new` keyword bypasses the pool's re-use mechanism, forcing the allocation of a distinct object. In contrast, directly assigning a string literal (e.g., `String s = "Hello"`) enables the JVM to re-use instances from the constant pool.
```java
String str1 = new String("John");
String str2 = new String("Doe");
```
![[图解字符串常量值 3]]

## 🔍 示例代码对比：

```java
String str1 = new String("Hello");
String str2 = "Hello";
```

这两行代码**看起来**是创建了相同的字符串 `"Hello"`，但**底层的内存分配策略完全不同**，我们逐步解释。


# 对比字符串的两种创建策略
## 第一种：`String str1 = new String("Hello");`

这个语句实际上是两步操作：

### 1️⃣ `"Hello"` —— **字符串字面量常量**

- `"Hello"` 是一个字符串字面量；
- **编译时**就被放入**字符串常量池（String Pool）**中；
- 该字符串常量池位于堆中（Java 7+）或方法区（Java 6 及以前）；
- JVM 确保常量池中只存在一份 `"Hello"`。

### 2️⃣ `new String("Hello")` —— **新建堆对象**
- `new` 会在堆上**重新创建一个新的 String 对象**，它的内容是常量池中的 `"Hello"` 的副本；
- `str1` 指向这个新创建的对象，而不是常量池中的对象。

👇 内存示意：

```
堆：        [String 对象（内容："Hello"）]  <-- str1
常量池：    [字符串常量："Hello"]
```

📌 **所以创建了两个对象**：一个在常量池中（隐式创建），一个在堆中（显式 new）。

## 第二种：`String str2 = "Hello";`

这是一个简单的**字面量赋值**，行为如下：

- 编译器检查字符串常量池中是否已有 `"Hello"`；
- 如果有，直接返回该对象的引用；
- 如果没有，则在常量池中创建 `"Hello"`；
- `str2` 引用常量池中的字符串对象。

👇 内存示意：

```
常量池：    [字符串常量："Hello"]  <-- str2
```

📌 **只创建了一个对象**，位于常量池中。

## 内存对比总结表：

| 代码                                   | 常量池是否创建 `"Hello"` | 是否在堆中新建对象 | 最终引用指向  |
| ------------------------------------ | ----------------- | --------- | ------- |
| `String str1 = new String("Hello");` | ✅ 是               | ✅ 是       | 堆上的新对象  |
| `String str2 = "Hello";`             | ✅ 是（或复用）          | ❌ 否       | 常量池中的对象 |
## 衍生问题：`str1 == str2` 结果是什么？

```java
System.out.println(str1 == str2);  // false
```

- == 比较的是引用地址
- str1 是堆上的新对象
- str2 是常量池中的对象
- 所以结果为 false

如果使用 `.equals()` 则比较的是字符串内容：
```java
System.out.println(str1.equals(str2));
```


## 总结

|点|`new String("Hello")`|`"Hello"`|
|---|---|---|
|是否使用堆|✅ 是|❌ 否（默认只在常量池）|
|是否使用常量池|✅ 是（间接使用）|✅ 是|
|创建几个对象|通常 2 个|通常 1 个|
|内存占用|更高|更低|
|推荐方式|不推荐|推荐，尤其是在字符串常量场景|
