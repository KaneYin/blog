假设我们现在要给学生添加一个状态（跑步、学习、睡觉），外部可以实时获取这个学生的状态：
```java
public class Student {  
	//状态，可以是：跑步、学习、睡觉 这三个之中的一种
    private String status;  
  
    public String getStatus() {  
        return status;  
    }  
    public void setStatus(String status) {  
        this.status = status;  
    }  
}
```
但是这样会出现一个问题，当我需要把这个设置学生状态的方法暴露出来的时候，似乎外部可以不按照我规定的规则，传入一些其他字符串，并且这并不违反Java的语法规则：
```java
public class test {  
    public static void main(String[] args) {  
        Student s1 = new Student();  
        s1.setStatus("打豆豆");  
        System.out.println(s1.getStatus());  
    }  
}
```
这样明显是不够严谨的，我希望开发者拿到使用的就是==我预先定义好的状态==，所以可以使用枚举类型来完成这个需求：
```java
public enum Status {  
    RUNNING,SLEEPING,SLEEP;  
}
```
使用枚举类型也非常方便，就像使用普通类型一样：
```java
public class Student {  
    private Status status;  
  
    public Status getStatus() {  
        return status;  
    }  
    public void setStatus(Status status) {  
        this.status = status;  
    }  
}
```
