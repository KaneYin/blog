# 类、超类和子类


## 重写方法

子类可以添加字段、增加方法或覆盖超类的方法，不过，继承绝不会删除任何字段或方法。

> C++：**在 Java 中使用关键字 super 调用超类的方法，在 C++中则使用超类名加上：：操作符的形式。**
> 例如，Manager 类的 getSalary 方法要调用 Employee::getSalary。

## 子类构造方法

在这个例子的最后，我们来提供一个构造器。
```java
public Manager(String name, double salary, int year, int month, int day)
{
	// 调用超类 Employee 中带有 n、s、year、month 和 day 参数的构造器 的简写形式
	super(name, salary, year, month, day);
	bonus = 0;
}
```
由于 Manager 类的构造器不能访问 Employee 类的私有字段，所以必须通过一个构造器来初始化这些私有字段。可以利用特殊的 super 语法调用这个构造器。**使用 super 调用构造器的语句必须是子类构造器的第一条语句**。
==如果构造子类对象时没有显式地调用超类的构造器，那么超类必须有一个无参数构造器。这个构造器要在子类构造之前调用。==

> 回想一下，关键字 this 有两个含义：一个是指示私有化参数的引用，二是调用该类的其他构造器。类似的，super 关键字也有两个含义：一是调用超类的方法，二是调用超类的构造器。
> 用来调用构造器的时候，this 和 super 两个关键字紧密相关。调用构造器的语句只能作为另一个构造器的第一条语句出现。构造器参数可以传递给当前类的订一个构造器，也可以传递给超类的构造器。

下面给出一个例子来说明这个类的使用。
```java
Manager boss = new Manager("Carl Cracker", 80000, 1987, 12, 15);
boss.setBonus(5000);

// 下面定义一个包含 3 个员工的数组
var staff = new Employee[3];
staff[0] = boss;
staff[1] = new Employee("Harry Hacker",50000,1989,10,1);
staff[2] = new Employee("Tony Tester",40000,1990,3,15);

// 输出每个人的薪水
for(Employee e:staff)
	System.out.println(e.getName() + e.getSalary());

```

这里的 `staff[1] staff[2]` 仅输出了基本薪水，这是因为它们是 Employee 对象，而 `staff[0]`  是一个 manager 对象，它的 getSalary 方法会将奖金与基本薪水相加。

需要指出，尽管这里将 e 声明为 Employee 类型，但实际上 e 既可以引用 Employee 类型的对象，也可以引用 Manager 类型的对象。

当 e 引用 Employee 对象的时候，e.getSalary() 调用的是 Employee 类中的 getSalary 方法；当 e 引用 Manager 对象时，e.getSalary() 调用的则是 Manager 类中的 getSalary 方法。虚拟机知道 e 实际引用的对象类型，因此能够调用正确的方法。

==一个对象变量（例如，变量 e）可以指示多种实际类型，这一点称为多态，在运行时能够自动选择适当的方法，这称为动态绑定。==

## 继承层次结构
继承并不仅限于一个层次。例如，可以由 Manager 类派生 Executive 类。由一个公共超类派生出来的所有类的集合成为**继承层次结构**。
在继承层次结构中，从某个特定的类到其祖先的路径称为该类的继承链。
## 多态

在 Java 程序设计语言中，对象变量是多态的。一个 Employee 类型的变量既可以引用一个 Employee 类型的对象，也可以引用 Employee 类的任何一个子类的对象。
