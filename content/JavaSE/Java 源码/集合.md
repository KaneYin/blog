# 集合的体系结构
Java 中主要可以分为两类集合：单列集合、双列集合。主要区别其实就是单列集合一次添加一个数据，双列集合一次添加两个数据。
![[Java 中集合的体系结构]]
- List 系列集合：添加的元素**有序（指的是存取的有序）、可重复、有索引**
- Set 系列集合：添加的元素**无序、不重复、无索引**
## Collection
 这个接口定义了集合类的一些基本操作，方法如下：
```java
public interface Collection<E> extends Iterable<E>{

	// 这些是查询相关的操作

	// 获取当前集合中的元素数量
	int size();
	
	// 查看当前集合是否为空
	boolean isEmpty();
	
	// 查询当前集合中是否包含某个元素
	// 细节：底层是依赖 equals 方法进行判断是否存在的。
	// 所以，如果集合中存储的是自定义对象，也想通过 contains 方法判断是否包含，那么在 JavaBean 中，一定要重写 equals 方法
	boolean contains(Object o);
	
	// 生成当前集合的一个迭代器
	Iterator<E> iterator();
	
	// 把当前集合转换为对应的数组
	Object[] toArray();
	
	// 有参数的 toArray 方法，转换为对应类型的数组
	<T> T[] toArray(T[] a);
	
	// 向集合中添加元素，不同的集合类可能会对插入的元素有要求
	// 细节1：往 List 系列集合中添加数据，方法永远返回 true，因为 List 允许元素重复
	// 细节2：往 Set 集合里面添加数据，如果要添加的元素不存在 返回 true，但是如果要添加的元素已经存在，方法返回 false。
	boolean add(E e);
	
	// 移除集合中的某个元素
	// 细节1：因为 Collection 里面定义的是共性的方法，所以此时不能通过索引进行删除， 只能通过元素的对象进行删除，因为 Set 里面没有索引。
	// 细节2：方法有一个布尔类型的返回值，删除成功返回 true，删除失败返回 false
	boolean remove(Object o);
	// 批量执行的操作
	
	// 查询当前集合是否包含给定集合中的所有元素
	// 从数学角度来看，就是看给定集合是不是当前元素的子集
	boolean containsAll(Collection<?> c);
	
	// 添加给定集合中的所有元素
	// 数学上，就是求给定集合与当前集合的并集
	// 成功返回 true，失败返回 false
	boolean addAll(Collection<? extends E> c);
	
	// 移除给定集合中出现的所有元素，如果某个元素在当前集合中不存在，那么就忽略这个元素
	// 数学上，就是求当前集合与给定集合的差集
	// 移除成功返回 true，失败返回 false
	boolean removeAll(Collection<?> c);
	
	// Java8 新增方法，根据给定的 Predicate 条件进行元素移除操作
	default boolean removeIf(Predicate<? super E> filter);
	
	// 只保留当前集合中给定集合中出现的元素，其他元素一律移除
	// 数学上，就是当前集合与给定集合的交集
	// 移除成功返回 true，否则返回 false
	boolean retainAll(Collection<?> c);
	
	// 清空整个集合，删除所有元素
	void clear();
	
	
}
```
# 集合的遍历方式
Collection 的通用遍历方式：
- 迭代器遍历：迭代器的最大特点就是不依赖索引。
	- 迭代器在 Java 中的类是 Iterator，迭代器是集合专用的遍历方式
- 增强 for 遍历
- Lambda 表达式遍历
## 迭代器遍历
### Collection 集合获取迭代器
 ```java
// 返回迭代器对象，默认指向当前集合的 0 索引
Iterator<E> iterator();
```
###  Iterator 中的常用方法
```java
// 判断当前位置是否有元素，有元素返回 true，没有元素返回 false
boolean hasNext();
// 获取当前位置的元素，并将迭代器对象移向下一个位置
E next();
```

###  一个使用迭代器遍历 Collection 中元素的示例
```java
public class MyIterator {  
    public static void main(String[] args) {  
        Collection<String> collection = new ArrayList<>();  
        collection.add("A");  
        collection.add("B");  
        collection.add("C");  
        collection.add("D");  
  
        // 创建一个迭代器对象，迭代器好比是一个箭头，默认指向集合的第一个元素
        Iterator<String> it = collection.iterator();
        // 判断是否有元素
        while(it.hasNext()){
	        // 获取并打印元素  
            System.out.println(it.next());  
        }  
    }  
}
```
迭代器中细节注意点：
1. 如果当前迭代器 hasNext() 方法已经为 false，但是强行调用 next 方法，那么会报错 NoSuchElementException。由于迭代器遍历是不依赖于索引的，所以报错并不是 IndexOutOfBounds 异常，而是没有元素的异常。
2. 迭代器遍历完毕，指针不会复位。如果想要再次遍历集合，只能再获取一个迭代器对象。
3. 循环中只能使用一次 next 方法。
4. 迭代器遍历的时候，不能用集合的方法进行增加或者删除。只能使用迭代器中的方法进行删除，也能成功删除集合中的内容。但是对于添加，暂时没有方法。
##  增强 For 循环遍历
- 增强 for 的底层就是迭代器，为了简化迭代器的代码书写。
- 是 JDK5 之后出现的，其内部原理就是一个 Iterator 迭代器。
- 所有的单列集合和数组才能用增强 for 进行遍历。
- 修改增强 for 中的变量，不会改变集合中原本的数据。

**格式：**
```java
for(元素的数据类型 变量名：数组或者集合){
	
}
```
比如：
```java
for(String s : list){
	System.out.println(s);
}
```
###  Lambda 表达式遍历
得益于 JDK8 开始的新技术 Lambda 表达式，提供了一种更简单、更直接的遍历集合方式。
```java
// 1. 使用匿名内部类的形式  
// 底层原理：其实也会自己遍历集合，依次得到每一个元素  
// 把得到的每一个元素，传递给下面的 accept 方法  
collection.forEach(new Consumer<String>() {  
    @Override  
    // s 表示集合中的每一个数据  
    public void accept(String s) {  
        System.out.println(s);  
    }  
});  
// 2. 改进为 Lambda 表达式进行简化  
// () -> {}  
collection.forEach(s -> System.out.println(s));
```
# Java List
List 集合的特点：
- 有序：存和取的元素顺序一致
- 有索引：可以通过索引操作元素
- 可重复：存储的元素可以重复

在使用 List 的过程中，经常会犯这样的错误：`List<E> ls = new List<>();`
**由于List是接口，因此无法从中创建对象。** 为了使用 List 接口的功能，可以使用以下的类：
- 数组列表 ArrayList
- 链表 LinkedList
- 向量 Vector
- 堆栈 Stack

## 如何使用 List
在 Java 中，必须导入 java.util.List 包才能使用 List。
```java
// List 的 ArrayList 实现
List<Integer> ls1 = new ArrayList<>();

// List 的 LinkedList 实现
List<Integer> ls2 = new LinkedList<>();
```
这里，我们已经创建 ArrayList 和 LinkedList 类的对象 ls1、ls2，现在这些对象可以使用 List 接口的功能。
## List 中的方法与属性
List 接口包括 Collection 接口的所有方法。因为 Collection 是 List 的超级接口。
- add(int index, E element): 将元素添加到指定的位置
- addAll(): 将一个列表的所有元素添加到另一个
- set(int index, E element): 更改列表中指定位置的元素
- remove(int index): 从列表中指定位置删除一个元素
- removeAll(): 从列表中删除所有元素
- clear(): 从列表中删除所有元素，比上面的方法效率更高。
- size(): 返回列表的长度
- toArray(): 将列表转换为数组
- contains(): 如果列表包含指定的元素，返回 true。
## List 集合的遍历方式
- 迭代器遍历：如果在遍历过程中需要删除元素，使用迭代器。
- 列表迭代器：遍历过程中需要添加元素，使用列表迭代器。
- 增强 For 循环、Lambda：仅仅遍历，可以使用这两种方式。
- 普通 for：如果遍历的时候想操作索引，可以使用普通 for。

```java
public class ArrayTest {  
    public static void main(String[] args) {  
        // 无初始值初始化列表  
        List<Integer> ls1 = new ArrayList<>();  
        // 在尾部添加元素  
        ls1.add(5);  
        ls1.add(4);  
        ls1.add(3);  
        ls1.add(2);  
        ls1.add(1);  
        ls1.add(0,-1); // 在索引 0 的位置，插入数字 -1  
        // 迭代器遍历  
        Iterator<Integer> iterator = ls1.iterator();  
        while (iterator.hasNext()) {  
            System.out.print(iterator.next() + " ");  
        }  
        System.out.println();  
  
        // 通过索引遍历列表  
        for(int i = 0; i < ls1.size(); i++) {  
            System.out.print(ls1.get(i) + " ");  
        }  
        System.out.println();  
        // 增强 for 遍历  
        for(Integer i : ls1){  
            System.out.print(i + " ");  
        }  
        System.out.println();  
        // Lambda  
        ls1.forEach(i -> System.out.print(i + " "));  
        System.out.println();  
  
    }  
}
```

# ArrayList
## 集合底层原理
1. 利用空参构造创建的集合，在底层创建一个默认长度为 0 的数组。
2. 添加第一个元素时，底层会创建一个默认长度为 10 的数组。
3. 存满的时候，会自动扩容 1.5 倍。
4. 如果一次添加多个元素，1.5 倍放不下，则新创建的数组的长度以实际为准。

```java
// Java 源码

public boolean add(E e){
	modCount++;
	add(e, elementData, size);
	return true;
}

public void add(E e, Object[] elementData, int s){
	if(s == elementData.length){
		elementData = grow();
	}
	elementData[s] = e;
	size = s + 1;
}

private Object[] grow(){
	return grow(size + 1);
}

private Object[] grow(int minCapacity){
	int oldCapacity = elementData.length;
	if(oldCapacity > 0 || elementData != DEFAULTCAPACITY_EMPTY_ELEMENTDATA){
		int newCapacity = ArraysSupport.newLength(oldCapacity,
						minCapacity - oldCapacity,
						oldCapacity >> 1);
		return elementData = Arrays.copyOf(elementData, newCapacity);
	}else{
		return elementData = new Object[Math.max(DEFAULT_CAPACITY, minCapacity)];
	}
}

public static int newLength(int oldLength, int minGrowth, int prefGrowth){
	int prefLength = oldLength + Math.max(minGrowth, prefGrowth);
	if(0 < prefLength && prefLength <= SOFT_MAX_ARRAY_LENGTH){
		return prefLength;
	}else{
		return hugeLength(oldLength, minGrowth);
	}
}
```
# Set 单列集合
## Set 系列集合的特点
- 无序：存取的顺序可能不一致。
- 不可重复：可以去除数据的重复。
- 无索引：没有带索引的方法，所以不能使用普通 for 循环遍历，也不能通过索引来获取元素。
## Set 集合的实现类
- HashSet：无序、不重复、无索引
- LinkedHashSet：有序、不重复、无索引
- TreeSet：可排序、不重复、无索引

**Set 接口中的方法基本上与 Collection 的 API 一致。**

## HashSet 底层原理
- HashSet 集合底层采用哈希表存储数据
- 哈希表是一种对于增删改查数据性能都较好的数据结构

## 双列集合的特点
- 双列集合一次需要存一对数据，分别为键和值。

## Map 的遍历方式
- 键找值：首先获取到所有键的集合，然后遍历键的集合，根据每一个键找到对应的值。
```java
public class MapTravelTest {  
    public static void main(String[] args) {  
        // Map 集合的第一种遍历方式  
        Map<String,Integer> map = new HashMap<>();  
        map.put("A",1);  
        map.put("B",2);  
        map.put("C",3);  
  
        // 遍历  
        // 首先获取所有的键，把这些键放到一个单列集合当中  
        Set<String> keys = map.keySet();  
        // 遍历单列集合，得到每一个键  
        for(String key:keys){  
            System.out.print(key + "=");  
            // 利用键获取每一个值 get  
            System.out.println(map.get(key));  
        }  
    }  
}
```
- 键值对遍历：每次遍历获取里面的键值对对象，然后通过 getKey 方法获取键；用 getValue 方法获取值。
```java
	public class MapTravelTest {  
    public static void main(String[] args) {  
        // 第二种遍历方式：通过键值对对象进行遍历  
  
        // 通过一个方法获取所有的键值对对象，返回一个 Set 集合  
        Set<Map.Entry<String, Integer>> entries = map.entrySet();  
        // 遍历 entries 集合，得到里面的每一个键值对对象  
        for(Map.Entry<String, Integer> entry:entries){  
            // 利用 entry 里的 get 方法获取键和值  
            System.out.println(entry.getKey() + "=" + entry.getValue());  
        }  
    }  
}
```

## HashMap 的使用
HashMap 是 Map 集合的底层实现，并且没有独特的方法。这里介绍 HashMap 的特点：
- HashMap 是 Map 里面的一个实现类。
- 没有额外需要学习的特有方法，直接使用 Map 里面的方法就可以了。
- 特点都是由键决定的：无序、不重复、无索引。
- HashMap 和 HashSet 的底层原理都是一模一样的，都是哈希表结构。
	- 也就是说，底层依赖 **hashCode** 方法和 **equals** 方法保证键的唯一。
- 如果键存储的是自定义对象，需要重写 hashCode 和 equals 方法；如果值存储自定义对象，不需要重写 hashCode 和 equals 方法。

#### HashMap 如何存储元素
1. 当冲突个数小于 8 个的时候，冲突的哈希值使用链表来存储，链表中结点的定义如下：
在 HashMap 中，可以看到一个名为 Node 的内部类，其实这个 Node 就是用来存储哈希表中的键值对元素的：

```java
// Java 源码

// Node 内部类是实现了 Entry 这个接口，是一个 Entry 对象
static class Node<K,V> implements Map.Entry<K,V> {
	// hash 属性其实就是根据 Key 计算出来的哈希值
    final int hash;  
    final K key;  // key
    V value;  // Value
    // 由于 HashMap 底层是数组加链表加红黑树实现的，所以 next 属性就是下一个结点的地址值（也就是用来解决哈希冲突的）。
    Node<K,V> next;  
  
    Node(int hash, K key, V value, Node<K,V> next) {
        this.hash = hash;  
        this.key = key;  
        this.value = value;  
        this.next = next;  
    }  
  
    public final K getKey()        { return key; }  
    public final V getValue()      { return value; }  
    public final String toString() { return key + "=" + value; }  
  
    public final int hashCode() {  
        return Objects.hashCode(key) ^ Objects.hashCode(value);  
    }  
  
    public final V setValue(V newValue) {  
        V oldValue = value;  
        value = newValue;  
        return oldValue;  
    }  
  
    public final boolean equals(Object o) {  
        if (o == this)  
            return true;  
  
        return o instanceof Map.Entry<?, ?> e  
                && Objects.equals(key, e.getKey())  
                && Objects.equals(value, e.getValue());  
    }  
}
```
2. 当冲突的个数大于 8 个的时候，冲突元素的存储方式由链表转换为红黑树，红黑树的结点定义如下：
```java
// Java 源码
static final class TreeNode<K,V> extends LinkedHashMap.Entry<K,V> {
	// 记录父节点的地址值
    TreeNode<K,V> parent;  // red-black tree links
    // 左子结点的地址  
    TreeNode<K,V> left;
    // 右子结点的地址  
    TreeNode<K,V> right;  
    TreeNode<K,V> prev;    // needed to unlink next upon deletion 
    // 为真表示是红色，为假表示是黑色 
    boolean red;  
    TreeNode(int hash, K key, V val, Node<K,V> next) {  
        super(hash, key, val, next);  
    }  
  
    /**  
     * Returns root of tree containing this node.     */    final TreeNode<K,V> root() {  
        for (TreeNode<K,V> r = this, p;;) {  
            if ((p = r.parent) == null)  
                return r;  
            r = p;  
        }  
    }
```
由于 TreeNode 的继承结构，所以除了红黑树所需的属性以外，TreeNode 中还会记录 Node 中的基础数据（hash, key, value, next）

```java
 * The table, initialized on first use, and resized as * necessary. When allocated, length is always a power of two. * (We also tolerate length zero in some operations to allow * bootstrapping mechanics that are currently not needed.) */
```

#### 核心方法 - put(key, val)
添加元素的时候需要考虑到三种情况：
1. 待添加元素的数组位置为 null，直接添加到数组中即可。
2. 待添加元素的数组位置不为 null，键不重复，挂在该结点下面形成链表或者红黑树。
3. 待添加元素的数组位置不为 null，键重复，元素覆盖。
```java

// 参数一：键，参数二：值
// 返回值：被覆盖元素的值，如果没有覆盖，返回 null
public V put(K key, V value){
	return putVal(hash(key), key, value, false, true);
}
// 利用键计算出对应的哈希值，再把哈希值进行一些额外的处理
// 简单理解：返回值就是键的哈希值
static final int hash(K key){
	int h;
	return (key == null) ? 0 : (h = key.hashCode() ^ (h >>> 16));
}
// 参数一：键的哈希值
// 参数二：键，参数三：值
// 参数四：如果键重复，是否保留，默认为 false，表示重复键覆盖；如果为 true，表示重复键不覆盖

final V putVal(int hash, K key, V value, boolean onlyIfAbsent, boolean evict){
	// 局部变量，记录哈希表中数组的地址值
	Node<K, V>[] tab;
	// 临时变量，记录键值对对象
	Node<K, V> p;
	// 当前数组的长度
	int n;
	// 索引
	int i;
	
	// 哈希表中数组地址给局部变量 tab，主要是为了快速访问
	tab = table;
	if(tab == null || (n = tab.length) == 0){
		// 1.如果当前是第一次添加数据，底层会创建一个默认长度为 16，加载因子为 0.75 的数组
		// 2.如果不是第一次添加数据，会看数组中的元素是否达到扩容条件，
		// 如果没有达到扩容条件，底层不会做任何操作
		// 如果达到了扩容条件，底层会把数组扩容为原先的两倍，并把数据全部转移到新的哈希表中。
		tab = resize();
		// 当前数组的长度赋值给 n
		n = tab.length;
	}
	// 拿着数组的长度和键的哈希值进行计算，计算出当前键值对对象在数组中的位置
	i = (n - 1) & hash;
	// 获取数组中对应元素的数据
	p = tab[i];
	if (p == null){
		// 如果当前数组中这个位置没有元素，底层会创建一个键值对对象，直接放到数组中
		tab[i] = newNode(hash, key, value, null);
	}
    else {
	    // 进入 else，说明待插入位置已经存在结点，挂在该结点下形成链表或者红黑树
	    Node<K,V> e;
	    K k;
    if (p.hash == hash &&  
        ((k = p.key) == key || (key != null && key.equals(k))))  
        e = p;
        
        
    else if (p instanceof TreeNode){
	    // 判断数组中获取出来的键值对是不是红黑树中的结点
	    // 如果是，调用 putTreeVal 方法，把当前结点按照红黑树规则添加到树中
	    e = ((TreeNode<K,V>)p).putTreeVal(this, tab, hash, key, value);  
    }
        
    else {
	    // 如果从数组中获取的键值对对象不是红黑树结点
	    // 表示此时下面挂的是链表
	    // binCount 表示链表中结点的个数
        for (int binCount = 0; ; ++binCount) {
	        // 循环的作用是找到链表的最后一个结点也就是 (e = p.next)==null
            if ((e = p.next) == null) {
	            // 当找到链表的尾结点以后，创建一个新的结点，然后使 p.next 指向这个新结点
                p.next = newNode(hash, key, value, null);  
                if (binCount >= TREEIFY_THRESHOLD - 1){
	                // 判断链表的长度是否超过 8，超过，就调用treeifyBin
	                // treeifyBin该方法底层还会判断数组的长度是否大于等于64
	                // 如果两个条件都满足，就会把链表转换为红黑树
	                treeifyBin(tab, hash);  
                }
                break;  
            }  
            if (e.hash == hash &&  
                ((k = e.key) == key || (key != null && key.equals(k))))  
                break;  
            p = e;  
        }  
    }
    // 如果 e 为 null，表示当前不用覆盖任何元素
    if (e != null) {   
        V oldValue = e.value;  
        if (!onlyIfAbsent || oldValue == null)  
            e.value = value;  
        afterNodeAccess(e);  
        return oldValue;  
    } 
	// threshold: 记录的就是数组长度 * 0.75，也就是哈希表的扩容时机
	if(++size > threshold){
		resize();
	}
	// 表示当前没有覆盖任何元素，直接返回 null
	return null;
}
```
## LinkedHashMap
特点：
- 由键决定：**有序**（这是 LinkedHashMap 的特点）、不重复、无索引。
- 这里的有序指的是**保证存储和取出的元素顺序一致。**
- 原理：底层数据结构依然是哈希表，只是每个键值对元素又额外的多呢一个双链表的机制记录存储的顺序。

```java
public class LinkedHashMapTest {  
    public static void main(String[] args) {  
        // 创建集合  
        LinkedHashMap<String,Integer> lhm = new LinkedHashMap<>();  
  
        // 添加元素  
        lhm.put("A",1);  
        lhm.put("B",2);  
        lhm.put("C",3);  
  
        // 打印集合  
        System.out.println(lhm); // {A=1, B=2, C=3}  
        // 打印结果的顺序和添加元素的顺序相同  
    }  
}
```

## 可变参数
假设需要定义一个方法求和，改方法可以灵活的完成如下需求：
计算 2 个数据的和、计算 3 个数据的和、计算 4 个数据的和、计算 n 个数据的。
```java
public class ArgsDemoTest {  
    public static void main(String[] args) {  
        //JDK 5  
        // 可变参数：方法形参的个数是可以发生变化的：0 1 2 3 ...  
        // 格式：属性类型 ... 名字  
        // int ... args  
  
        // 可变参数 和 数组作为参数写法的对比  
        System.out.println(getSum1(1,2));;  // 没有任何限制，想要传递几个参数都可以  
  
        int[] arr = {1,2,3,4,5,6,7,8,9};  
        System.out.println(getSum2(arr));  
    }  
    // 使用可变参数的写法  
    // 可变参数的底层就是一个数组，但是不需要我们自己创建了，Java 会帮我们创建好  
    public static int getSum1(int...args){  
        // 可以尝试打印一下 args 这个参数 输出：[I@36baf30c，表明底层实现就是一个数组  
        // System.out.println(args);  
        int sum = 0;  
        for(int i : args){  
            sum += i;  
        }  
        return sum;  
    }  
  
    // 使用数组作为参数的写法  
    public static int getSum2(int[] arr){  
        int sum = 0;  
        for(int i : arr){  
            sum += i;  
        }  
        return sum;  
    }  
}
```
可变参数使用过程中需要注意的细节：
1. 在方法的形参中最多只能写一个可变参数。
2. 在方法当中，如果除了可变参数以外，还有其他的形参，那么可变参数要写在最后。
