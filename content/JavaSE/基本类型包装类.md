Java并不是纯面向对象的语言，虽然Java语言是一个面向对象的语言，但是其中的基本数据类型却不是面向对象的，如果想要通过面向对象的方式操作他们，Java提供了基本类型的包装类。

包装类支持自动装箱，可以直接将一个对应的基本类型值作为包装类型的引用变量的值：
```java
public static void main(String[] args) {  
    Integer i = 10; //用int类型值作为包装类型使用  
}
```
为什么能够实现自动装箱，其实是编译器对语法进行了简写：
```java
public static void main(String[] args){
	/**
	* public static Integer ValueOf(int i)
	* 返回指定 int 值的 Integer 实例，通常应该优先使用这个方法而不是构造函数，
	*/

	Integer i = Integer.ValueOf(10); //这个方法和上面的写法是等价的
}
```
既然能够实现自动装箱，那么也肯定能够实现自动拆箱：
```java
public static void main(String[] args) {  
    Integer i = 10; //用int类型值作为包装类型使用
    int a = i;  
    //这种写法本质上就是:
    //通过这种方法把包装类变成与之对应的基本数据类型
    // public int intValue() 将包装类型的值作为int返回
    int a = i.intValue();
}
```
