单元测试：就是针对最小的功能单元（方法），编写代码进行正确性测试

**在单元测试以前，我们是如何测试编写的方法是否正确的？**
- 只能在 main  方法中编写测试代码，调用其他方法进行测试。
- 无法实现自动化测试，一个方法测试失败，可能会影响其他方法的测试。因为 main 是 Java 程序的启动入口，如果不能运行成功会直接报错。
- 无法得到测试报告，需要我们自己观察测试是否成功。
## Junit 单元测试框架
可以对方法进行测试，是由第三方公司开源出来的，很多开发工具已经集成了 Junit，比如 IDEA。
**优点：**
- 可以灵活的编写测试代码，可以针对某个方法执行测试，也支持一键完成对全部方法的自动化测试， 并且各自独立。
- 不需要自己分析测试结果，会自动生成测试报告。
