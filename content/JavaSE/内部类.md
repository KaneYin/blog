内部类顾名思义，就是创建在成员或者方法里面。
# 成员内部类

我们可以直接在类的内部定义成员内部类：
```java
/**  
 * 成员内部类  
 */  
public class Test {    
    // 内部类也是类，所以说里面可以有成员变量、方法等，甚至可以继续套娃一个内部类  
    public class Inner{  
        public void test(){  
            System.out.println("我是一个内部类");  
        }  
    }  
}
```
成员内部类和成员方法一样，是**对象所有的，而不是类所有的**，如果我们想要使用成员内部类，就需要：
```java
/**  
 * 成员内部类  
 */  
public class Test {  
    public static void main(String[] args) {  
        // 首先需要创建一个外部类的对象  
        Test test = new Test();  
        // 创建成员内部类  
        Test.Inner inner = test.new Inner();  
        inner.test();  
    }  
  
    // 内部类也是类，所以说里面可以有成员变量、方法等，甚至可以继续套娃一个内部类  
    public class Inner{  
        public void test(){  
            System.out.println("我是一个内部类");  
        }  
    }  
}
```

成员内部类中也可以使用访问权限控制，如果将这个类权限改为 private，那么我们就像把成员变量访问权限变为私有一样，外部是无法访问到这个类的。


内部类可以使用外部类中的属性，但**是这个属性值是由外部类对象决定的**：
```java
public class Inner {  
    private String name;  
  
    Inner(){};  
    Inner(String name){  
        this.name = name;  
    }  
  
    public class InnerClass{  
        public void test(){  
            System.out.println("我是一个内部类：" + name);  
        }  
    }  
}
```

```java
public class Test {  
    public static void main(String[] args) {  
        Inner innera = new Inner("小红");  
        Inner innerb = new Inner("小明");  
  
        //依附于 innera 创建的内部类，name属性就是 innera 的  
        Inner.InnerClass innerClassa = innera.new InnerClass();  
        innerClassa.test(); // 我是一个内部类：小红  
  
        // 依附于 innerb 创建的内部类，name属性就是 innerb 的  
        Inner.InnerClass innerClassb = innerb.new InnerClass();  
        innerClassb.test(); // 我是一个内部类：小明  
    }  
}
```

上面这张图片可以很好地解释内部类与外部类对象之间的关系。

既然内部类能够访问外部类的成员变量与成员方法，那么反过来，外部类能够访问内部类的成员变量与成员方法吗？其实是不能的，只要理解了上图就很好理解问什么不能访问了，因为对象内部类是在外部类创建对象之后才能够创建的，内部类的对象都还没有创建，怎么访问内部类对象里面的成员变量和成员方法呢？


如果在内部类中定义了同名的变量，应该如何访问：
```java
/**  
 * 展示内部类如何调用同名的变量  
 */  
public class Inner2 {  
    private String name;  
  
    public class InnerClass{  
        private String name;  
  
        public void test(String name){  
            System.out.println("name:" + name); // 就近原则，最近的是参数  
            System.out.println("name:" + this.name); 
            // 在内部类中使用this关键字，只能表示内部类对象  
            System.out.println("name:" + Inner2.this.name); 
            // 如果需要指定为外部类的变量，需要在前面添加外部类名称  
        }  
    }  
}
```
包括对方法的调用和super关键字的使用，都是一样的：
```java
public class Inner2 {  
    private String name;  
  
    public class InnerClass{    
        public void test2(){  
            this.toString();   //内部类自己的toString方法  
            super.toString();  //内部类父类的toString方法  
  
            Inner2.this.toString(); //外部类的toString方法  
            Inner2.super.toString(); //外部类父类的toString方法  
        }  
    }  
}
```

# 静态内部类

之前讲到了成员内部类，类似于类的成员变量和成员方法一样，是属于对象的。同样的，静态内部类就像静态方法和静态变量一样，是属于某个类的，可以直接创建使用：
```java
public class StaticInner {  
    public String name;  
    public StaticInner(String name) {  
        this.name = name;  
    }  
  
    //在前面加上 static 关键字，让内部类变成静态的  
    public static class StaticInnerClass{  
        public void test(){  
            System.out.println("我是静态内部类");  
        }  
    }  
}
```

不需要依附任何对象，我们可以直接创建静态内部类的对象：
```java
public class Test {  
    public static void main(String[] args) {  
        // 使用静态内部类  
        StaticInner.StaticInnerClass staticInnerClass = new StaticInner.StaticInnerClass();  
        staticInnerClass.test();  
  
    }  
}
```

静态内部类由于是静态的，所以相对于外部来说，整个内部类都处于静态上下文（注意只是相当于外部来说）是无法访问到外部类的非静态内容的。
其实很容易理解，因为静态内部类是属于外部类的，不依赖于任何对象，那么如果要直接访问外部类的非静态属性，那么应该访问外部类哪个对象的呢？这样说不通。

# 局部内部类

局部内部类就像局部变量一样，可以在方法中定义：
```java
public class Test{

	private final String name;
	public Test(String name){
		this.name = name;
	}
	
	public void hello(){
		// 直接在方法中创建局部内部类
		class Inner{
		
		}
	}
}
```

在方法中定义的类，作用范围也只限于这个方法体中。
不过这种类型的局部内部类，使用频率非常低，基本上用不到，了解即可。

# 匿名内部类
匿名内部类是使用频率非常高的一种内部类，是局部内部类的简化版本。
```java
/**  
 * 一个抽象类以及其中的抽象方法  
 */  
public abstract class Student {  
    public abstract void test();  
}
```

```java
/**  
 * 匿名内部类的演示使用  
 */  
public class Test {  
    public static void main(String[] args) {  
        /**  
         * 一般情况下，如果想要创建抽象类或者接口的对象只能用子类继承抽象类或者实现接口  
         * 但是通过匿名内部类，可以不通过子类直接实现抽象类中的抽象方法  
         *  
         */  
        Student student = new Student() { 
        //在创建对象的时候，后面加上花括号，把未实现的方法实现了  
            @Override  
            public void test() {  
                System.out.println("我是匿名内部类中的抽象方法");  
            }  
        };  
        student.test();  
    }  
}
```
此时这里创建出来的 Student 对象，就是一个已经实现了抽象方法的对象，这个抽象方法就直接定义好了，甚至没有名字，就可以直接创建出对象。
匿名内部类可以直接使用类中的属性（因为**它本质上就相当于对应类型的子类**），所以说：
```java
public class Test {  
    public static void main(String[] args) {  
        /**  
         * 一般情况下，如果想要创建抽象类或者接口的对象只能用子类继承抽象类或者实现接口  
         * 但是通过匿名内部类，可以不通过子类直接实现抽象类中的抽象方法 
         */  
        Student student = new Student() {
            String name;  
              
            @Override  
            public void test() {  
                System.out.println( name + "是匿名内部类中的抽象方法");  
            }  
        };  
        student.test();  
    }  
}
```
既然能够自己创建成员变量和成员方法使用，当然能够使用父类的成员变量和成员方法，这些的使用都和一般的子类相同。
所以匿名内部类实际上就是创建了一个子类，但是用的是抽象类的方法，所以是“匿名”；而且由于是在创建抽象类的时候直接定义的，所以是”内部类“。

对于接口来说，使用方式也是一样的，比如创建一个 Study 接口：
```java
/**  
 * 使用接口演示匿名内部类的使用  
 */  
public interface Study {  
    public void study();  
}
```

```java
/**  
 * 匿名内部类的演示使用  
 */  
public class Test {  
    public static void main(String[] args) {  
  
        Study s = new Study() {  
            @Override  
            public void study(){  
                System.out.println("我是接口类中的方法");  
            }  
        };  
        s.study();  
    }  
}
```

当然，不只是有抽象类和接口可以创建匿名内部类，普通的类也可以，只不过意义不大，一般情况下只是为了一些额外的初始化工作。
# Lambda 表达式

前面学习了如何使用匿名内部类，可以通过这种方式创建一个临时的实现子类。

特别的，如果这个接口中有且仅有一个待实现的抽象方法，那么我们可以将匿名内部类简写为 Lambda 表达式：
```java
/**  
 * Lambda 表达式的测试类  
 */  
public class Test {  
    public static void main(String[] args) {
	    // 比如之前的 study 接口，可以通过 Lambda 表达式改写为
        Study study = () -> System.out.println("我是 Lambda 表达式");
    }  
}
```

初学阶段，可以简单的理解为 Lambda 表达式就是匿名内部类的简写就行（Lambda 表达式的底层并不只是简单的语法糖替换，可以在新特性中了解）

Lambda 表达式的编写规则如下：
- 标准格式为：`([参数类型 参数名称,]...) -> {代码语句，包括返回值}`
- 和匿名内部类不同，Lambda 仅支持接口，不支持抽象类。
- 接口内部必须有且仅有一个抽象方法（可以有多个方法，但是必须保证其他方法有默认实现，必须留一个抽象方法出来）

比如之前写的 Study 接口，只要求实现一个无参无返回值的方法，所以说就是最简单的形式：
```java
() -> System.out.println("我是 Lambda 表达式");
```

当然，可以在其中加上参数和返回值，不过要记得接口中的方法的参数类型和参数名称和 Lambda 表达式中的一定要对应起来：
```java
/**  
 * 演示更复杂的 Lambda 表达式的使用  
 */  
public interface Learn {  
    String learn(int a);  
}
```

```java
public class Test {  
    public static void main(String[] args) {  
        // 最简单形式的 lambda 表达式  
        Study study = () -> System.out.println("我是 Lambda 表达式");  
  
        // 包含参数和返回值的 lambda 表达式  
        Learn learn = (int a) -> {  
            System.out.println("我是一条 Lambda 表达式");  
            return "我今天学会了" + a;  
        };  
        System.out.println(learn.learn(2));  
    }  
}
```

如果 Lambda 表达式中只有一条 return 语句，那么可以省略 return 关键字和 `{}` 。
