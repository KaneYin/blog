# 布尔类型

| 运算符 | 描述     |
| --- | ------ |
| ==  | 是否相等   |
| !=  | 是否不等   |
| >   | 是否大于   |
| <   | 是否小于   |
| >=  | 是否大于等于 |
| <=  | 是否小于等于 |

# 判断语句

1. if 语句
	格式：

```python
if condition:
    do something
```

注意：
- 空格缩进，作用相当于定义 if 作用的范围

 2. if-else 组合使用
	格式：
```python
if condition:
    do something
else:
	do some other things
```

3. if-elif-else 组合使用
	格式：

```python
if condition1:
	do a
elif condition2:
	do b
elif condtion3:
	do c
else:
	do other things
```

注意：
- 判断是互斥并且有顺序的。
- else 可以不写，效果相当于几个单独的 if 语句
